# Go の正規表現（regexp、RE2）

## 対象と公式の資料

- 調べた処理系: Go 1.27.4 の `regexp` パッケージ
- 公式の資料
  - [regexp/syntax（書き方の一覧）](https://pkg.go.dev/regexp/syntax)
  - [regexp（パッケージの説明）](https://pkg.go.dev/regexp)
  - [RE2 の Syntax（使えない書き方の一覧も載っている）](https://github.com/google/re2/wiki/Syntax)

## 特徴

- 書き方は RE2 の書き方です。処理にかかる時間が、対象の文字列の長さに比例する範囲に収まることが保証されています。そのため、時間がかかりすぎて止まることがありません
- その代わり、**後方参照（`\1` など）と、先読み・後読みが使えません**。アトミックグループと強欲な繰り返しもありません
- 文字は UTF-8 のコードポイントとして扱います

## フラグ

フラグは正規表現の中に `(?i)` や `(?i:…)` のように書きます。

| フラグ | 意味 |
|---|---|
| `i` | 大文字と小文字を区別しない |
| `m` | `^` と `$` を各行の先頭と末尾にも一致させる |
| `s` | `.` を改行にも一致させる |
| `U` | 繰り返しの「できるだけ長く」と「できるだけ短く」を入れ替える |

`(?i)` は、書いた位置からグループの終わりまで効きます。あとに続く `|` の候補にも効きます（`a(?i)b|c` は `C` にも一致します。実際の結果）。`(?-)` や `(?i-)` のように `-` のあとにフラグがないと誤りになりますが、フラグのない `(?)` は誤りになりません（実際の結果）。g に当たるフラグはなく、`FindAllString` などの関数で、すべての一致を探します。

大文字と小文字を区別しない指定は、`\w` や `[[:lower:]]`、`\p{Lu}` などの文字の集まりにも効きます。`(?i:\w)` はケルビン記号（U+212A）と ſ（U+017F）にも一致します（実際の結果）。ただし `\b` と `\B` は、この指定があっても ASCII の英数字と `_` だけで境目を決めます。`(?i)x\b` は、ケルビン記号や ſ が続く `x` にも一致します（実際の結果）。

## 文字の集まり

- `\d` は `[0-9]`、`\w` は `[0-9A-Za-z_]`、`\s` は `[\t\n\f\r ]` で、どれも ASCII だけです。`\s` には垂直タブ（`\v`）も入りません
- `.` は LF 以外の 1 文字です。CR にも一致します
- `\pN`、`\p{Greek}`、`\p{Han}` のような Unicode の性質と、`[[:alpha:]]` などの ASCII の文字クラスが使えます。性質の名前は大文字と小文字、空白、`_` を区別しません（`\p{lu}` と `\p{Uppercase Letter}` は `\p{Lu}` と同じ。実際の結果）
- 一般カテゴリは `\p{Letter}`、`\p{Decimal_Number}` のような長い名前と、`\p{Punct}`、`\p{Digit}`、`\p{Cntrl}` のような別名でも書けます。ほかに `\p{LC}`、`\p{Any}`、`\p{ASCII}`、`\p{Assigned}` が使えました。`\p{White_Space}` のような二値の性質と、`\p{Hira}` のような用字の略称は使えません（実際の結果）

## 位置

- `^` は文字列の先頭です。m フラグで各行の先頭にも一致します
- `$` は文字列の末尾だけです。公式の資料には「`\Z` ではなく `\z` と同じ」とあり、最後の改行の直前には一致しません
- `\A` は先頭、`\z` は末尾です。`\Z` と `\G` は使えません
- `\b` と `\B` は ASCII の単語の区切りです
- `^*` や `\b+` のように、位置を表す部品を繰り返しても誤りになりません（実際の結果）

## グループ

- 名前付きグループは `(?P<name>…)` と `(?<name>…)` のどちらでも書けます
- 同じ名前のグループを置けました（実際の結果）。番号は左から順に付きます
- `(?'name'…)` と `(?#…)` は使えません

## 量指定子

- `x{n,m}` の数は 1000 までです
- `FindAllString` などですべての一致を探すとき、前の一致のすぐあとにある長さ 0 の一致は数えません。そのため、`x*` を `axx` に使うと、`xx` のあとの空の一致は出ません（実際の結果）
- `a{,3}` は文字のまま読みます。`a{01}` のように 0 で始まる回数も、回数の指定ではなく文字のまま読みます（実際の結果）

## エスケープ

- `\a \f \t \n \r \v`、8進数（`\123`）、`\x7F`、`\x{10FFFF}`、`\Q…\E` が使えます
- ASCII の記号の前の `\` はその記号を文字として読みます。`\あ` や `\é` のように、ASCII 以外の文字の前に `\` を付けると誤りになります（実際の結果）
- `\u0041`、`\cA`、`\e`、`\h`、`\R` などは使えません

## このツールでの扱い

- Go のモードで後方参照や先読み・後読みを書くと、書き方の誤りとして知らせます
- 「テスト」の欄では `\d` `\w` `\s` を ASCII だけの範囲に置き換えて動かします
