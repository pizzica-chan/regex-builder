# Python の正規表現（re）

## 対象と公式の資料

- 調べた処理系: Python 3.13 の `re` モジュール
- 公式の資料
  - [re — 正規表現操作（3.13）](https://docs.python.org/3.13/library/re.html)
  - [re — 正規表現操作（3.14）](https://docs.python.org/3.14/library/re.html)（3.14 で変わったところを確かめるため）
  - [What's New In Python 3.11](https://docs.python.org/3/whatsnew/3.11.html)（アトミックグループと強欲な繰り返しの追加）

## フラグ

| フラグ | 正規表現の中での書き方 | 意味 |
|---|---|---|
| `re.IGNORECASE`（`re.I`） | `(?i)` | 大文字と小文字を区別しない。Unicode の文字にも効く（Ü と ü など） |
| `re.MULTILINE`（`re.M`） | `(?m)` | `^` を各行の先頭、`$` を各行の末尾にも一致させる |
| `re.DOTALL`（`re.S`） | `(?s)` | `.` を改行にも一致させる |
| `re.VERBOSE`（`re.X`） | `(?x)` | 空白を無視し、`#` からをコメントにする |
| `re.ASCII`（`re.A`） | `(?a)` | `\d` `\w` `\s` `\b` を ASCII の文字だけにする |

`(?i)` のように範囲を区切らない書き方は、Python 3.11 から正規表現の先頭にしか書けません。途中に書くと誤りになります。範囲を区切る `(?i:…)` はどこにでも書けます。g に当たるフラグはなく、すべての一致を探すときは `re.findall` や `re.finditer` を使います。

## 文字の集まり

- `\d` は Unicode の 10 進数字（一般カテゴリ Nd）です。全角数字（０〜９）やほかの言語の数字にも一致します
- `\w` は `str.isalnum()` が真になる文字と `_` です。ひらがな、カタカナ、漢字、全角英数字にも一致します
- `\s` は `str.isspace()` が真になる文字です。全角スペースのほか、U+001C〜U+001F と U+0085 にも一致します（実際の結果。JavaScript の `\s` には含まれません）
- `.` は LF（`\n`）以外の 1 文字です。CR（`\r`）にも一致します
- `re.ASCII` を付けると、`\d` は `[0-9]`、`\w` は `[a-zA-Z0-9_]`、`\s` は `[ \t\n\r\f\v]` になります

## 位置

- `^` は文字列の先頭です。MULTILINE のときは、LF の直後にも一致します
- `$` は文字列の末尾と、**最後の LF の直前**に一致します。`a$` は「a＋LF」の a に一致します。MULTILINE のときは、各 LF の直前にも一致します
- `\A` は文字列の先頭です
- `\Z` は文字列の末尾だけに一致します（最後の改行の直前には一致しません）。ほかの多くの言語の `\z` と同じ意味です
- `\z` は Python 3.14 で追加されました。3.13 では書き方の誤りになります。3.14 では `\Z` は `\z` と同じ意味の別名になりました

## グループと参照

- 名前付きグループは `(?P<name>…)`、参照は `(?P=name)` です。`(?<name>…)` と `\k<name>` は使えません（3.13 で確かめました）
- 名前はPython の識別子として正しい名前にします
- `\1` から `\99` までが後方参照です。最初の数字が 0 のときと、3 桁の8進数のときは、8進数の文字コードになります
- 存在しないグループの番号を参照すると、書き方の誤りになります
- 一致しなかったグループを参照すると、その参照は失敗します（実際の結果）
- 後読み `(?<=…)` の中身は決まった長さの文字列にしか一致しないものにします。`abc` や `a|b` は書けますが、`a*` や `a{3,4}` は書けません
- アトミックグループ `(?>…)` と強欲な繰り返し（`*+` `++` `?+` `{m,n}+`）は Python 3.11 からです
- `(?#…)` はコメントです

## 量指定子

- `{m,n}` の m を省くと 0 回から、n を省くと上限なしになります。`a{,3}` は「a を 0〜3 回」です（ほかの多くの言語では文字のまま）
- 量指定子は直接重ねられません（`a**` は誤り）

## エスケープ

- `\a \b \f \n \r \t \v \x \u \U \N{名前} \\` と8進数が使えます
- `\cA` は使えません
- 英字の、意味のないエスケープ（`\q` など）は書き方の誤りです（3.6 から）

## 文字クラス

- `]` を文字として入れるときは、先頭に置くか `\]` と書きます
- `[` で始まる集まりや、`--` `&&` `~~` `||` を含む集まりは、将来の仕様の変更に備えて FutureWarning が出ます
- 文字クラスの中の `\1` などは後方参照ではなく8進数です

## このツールでの扱い

- Python のモードでは `(?P<name>…)` などの Python の書き方で入力します
- 「試す」の欄では正規表現を同じ意味の JavaScript の正規表現に置き換えて動かします。`\d` は `\p{Nd}`、`$` は「末尾か、最後の LF の直前」のように置き換えます
- `\w` は、JavaScript の `[\p{L}\p{N}_]` と、Python 3.13 の結果が BMP（U+0000〜U+FFFF）で一致することを確かめました。違いは Python 3.13 より新しい Unicode で追加された 16 文字だけです
