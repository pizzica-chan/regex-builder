# 正規表現の方言の資料

このツールが対応する 7 つの方言について、正規表現の仕様をまとめた資料です。どの資料も次の 2 つを元にしています。

- 公式の資料（言語やライブラリの公式のドキュメント）。各ファイルの「公式の資料」にリンクがあります。2026-11-23 に読みました
- 手元の処理系で実際に動かした結果。調べ方と結果は [tools/dialect-probe](../../tools/dialect-probe/) にあります

公式の資料と実際の結果が食い違ったときは、実際の結果に合わせてツールを作り、食い違いを各ファイルに書いています。

### 意味

| 部品 | JavaScript | Python | Java | PHP | C# | Go | サクラ |
|---|---|---|---|---|---|---|---|
| `\d` | 0〜9 | Unicode の数字（全角数字も） | 0〜9 | Unicode の数字 | Unicode の数字 | 0〜9 | Unicode の数字 |
| `\w` | 英数字と _ | ひらがな・漢字も含む | 英数字と _ | ひらがな・漢字も含む | ひらがな・漢字も含む | 英数字と _ | ひらがな・漢字も含む |
| `\s` が全角スペースに | 一致する | 一致する | しない | 一致する | 一致する | しない | 一致する |
| `.` が CR（`\r`）に | しない | する | しない | する | する | する | しない |
| `$` が最後の改行の直前に | しない | する | する | する | する | しない | 各行の末尾に一致 |
| 大文字と小文字を区別しない指定 | Unicode | Unicode | 英字だけ | Unicode | Unicode | Unicode | Unicode |
| 一致しなかったグループの参照 | 空文字列として一致 | 失敗 | 失敗 | 失敗 | 失敗 | （参照なし） | 失敗 |
| 絵文字などの数え方 | u フラグなしで 2 文字 | 1 文字 | 1 文字 | 1 文字 | 2 文字 | 1 文字 | 1 文字 |

PHP は日本語を 1 文字として扱うために `u` 修飾子を付けた場合の結果です。
