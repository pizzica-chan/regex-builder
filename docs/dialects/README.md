# 正規表現の方言の資料

このツールが対応する 10 の方言について、正規表現の仕様をまとめた資料です。どの資料も次の 2 つを元にしています（POSIX の資料は、実際の結果だけから書いています）。

- 公式の資料（言語やライブラリの公式のドキュメント）。各ファイルの「公式の資料」にリンクがあります。2026-11-23 に読みました
- 手元の処理系で実際に動かした結果。調べ方と結果は [tools/dialect-probe](../../tools/dialect-probe/) にあります

公式の資料と実際の結果が食い違ったときは、実際の結果に合わせてツールを作り、食い違いを各ファイルに書いています。

## 違いの早見表

POSIX の ERE と BRE は、書き方も一致の選び方（いちばん長い一致）も大きく違うので、表には入れず、[posix.md](posix.md) にまとめています。PowerShell は C# と同じ .NET の正規表現を使い、どの項目も C# と同じなので、表には入れていません（[powershell.md](powershell.md)）。

○ は使える、× は書き方の誤りになる、という意味です。表の値は [tools/dialect-probe/results/summary.txt](../../tools/dialect-probe/results/summary.txt) と、[tools/dialect-probe/cases.json](../../tools/dialect-probe/cases.json) の事例を各言語の処理系で動かした実際の結果から書いています。

### 意味

| 部品 | JavaScript | Python | Java | PHP | C# | Go | サクラ |
|---|---|---|---|---|---|---|---|
| `\d` | 0〜9 | Unicode の数字（全角数字も） | 0〜9 | Unicode の数字 | Unicode の数字 | 0〜9 | Unicode の数字 |
| `\w` | 英数字と _ | ひらがな・漢字も含む | 英数字と _ | ひらがな・漢字も含む | ひらがな・漢字も含む | 英数字と _ | ひらがな・漢字も含む |
| `\s` が全角スペースに | 一致する | 一致する | しない | 一致する | 一致する | しない | 一致する |
| `.` が CR（`\r`）に | しない | する | しない | する | する | する | しない |
| `$` が最後の改行の直前に | しない | する | する | する | する | しない | 各行の末尾に一致（CR の直前にも） |
| 改行をまたいで一致 | する | する | する | する | する | する | しない（1 行ずつ探す） |
| 大文字と小文字を区別しない指定 | Unicode | Unicode | 英字だけ | Unicode | Unicode | Unicode | Unicode |
| 区別しないときに同じとみなす文字 | ſ と s、ς と σ も | i・I・İ・ı も | 英字だけ | JavaScript と同じ | 小文字にして同じものだけ | JavaScript と同じ | ß と ss のような並びも |
| 区別しないときの `\p{Lu}` | a にも一致 | （`\p` なし） | ĸ にも一致 | a に一致しない | ĸ にも一致 | a にも一致 | a にも一致 |
| `\p{Han}` が「、」に | （`\p{Script=Han}` は）しない | （`\p` なし） | （`\p{IsHan}` は）しない | する | （用字の名前なし） | しない | しない |
| 一致しなかったグループの参照 | 空文字列として一致 | 失敗 | 失敗 | 失敗 | 失敗 | （参照なし） | 失敗 |
| 絵文字などの数え方 | u フラグなしで 2 文字 | 1 文字 | 1 文字 | 1 文字 | 2 文字 | 1 文字 | 1 文字 |

PHP は日本語を 1 文字として扱うために `u` 修飾子を付けた場合の結果です。
