# 正規表現ビルダー

部品のボタンを押して正規表現を組み立てると、その正規表現の意味を日本語で表示する静的 Web サイトです。JavaScript の正規表現の書き方に合わせています。

## 使い方

ファイル一式を Web サーバーに置き、`index.html` を開きます。ビルドは要りません。

一致の計算は Web Worker（画面とは別に動く処理）で行い、1.5 秒を超えたら打ち切ります。そのため、計算が終わらない正規表現を試しても画面は固まりません。`index.html` をファイルのまま開くと、ブラウザによっては Web Worker が動きません。その場合は画面と同じ処理で計算するので、打ち切りは働きません。

- 「正規表現」の欄：ページを下へ動かしても画面の上に残ります。入力した正規表現は、部品の種類ごとに色を分けて表示し、書き方に誤りがあれば、その場所に波線を引きます。見出しの横に一致の件数を表示します。フラグにマウスを乗せると、説明と、そのフラグを付けないときと付けたときの一致の違いが出ます。
- 「部品」の欄：ボタンを押すと、正規表現の入力欄のカーソルの位置に入ります。ボタンにマウスを乗せると、説明と例が出ます。「たたむ」ボタンで欄を閉じられます。
- 「意味」の欄：入力中の正規表現を、部品を順に並べた要約と、入れ子の詳しい説明で表示します。要約や説明の項目にマウスを乗せると、入力欄の対応する部分に色が付きます。反対に、入力欄の中にカーソルを置くと、その位置の部品の説明に色が付きます。
- 「試す」の欄：入れた文字列のうち、一致した部分に色を付け、グループに一致した部分にはグループごとの色の下線を引きます。一致の表の行にマウスを乗せると、その一致に枠が付きます。行を押すと、試す文字列の中でその一致を選んだ状態になります。
- 「行ごとに判定する」：試す文字列の各行を別々の文字列として調べます。行ごとに「一致するはず」「一致しないはず」を選ぶと、期待どおりかを表示します。
- 「配置」：ページ右上のメニューで、「部品」「意味」「試す」の欄の並べ方を6種類の型から選べます。選んだ型はブラウザに保存されます。幅が狭い画面では、「試す」「意味」「部品」の順に縦一列に並びます。
- 「消去」のボタンと「例を読み込む」：書き換えたあとに出る「元に戻す」のボタンか Ctrl+Z で、前の状態に戻せます。
- 「共有 URL」のボタン：正規表現、フラグ、試す文字列（2000文字まで）、行ごとの期待を URL に入れてコピーします。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 画面 |
| `style.css` | 見た目（OS の設定に合わせてダークモードにも切り替わる） |
| `regex-explain.js` | 正規表現を解析し、日本語の説明を作る |
| `app.js` | 部品、入力欄の色分け、説明の表示、一致の確認、行ごとの判定、共有 URL |
| `layout.js` | 欄の配置の型と切り替え |
| `match-core.js` | 試す文字列との一致を調べる処理。`match-worker.js` と `app.js` の両方から使う |
| `match-worker.js` | `match-core.js` の処理を、画面とは別の処理（Web Worker）で動かす |
| `favicon.svg`、`favicon.ico`、`apple-touch-icon.png` | ブラウザのタブやホーム画面に出るアイコン。`.ico` と `.png` は `python tools/make_favicons.py` で `favicon.svg` と同じ図形から作る（Pillow が要る） |

## 対応していないこと

- v フラグの集合演算（`[\w--\d]` など）の説明
